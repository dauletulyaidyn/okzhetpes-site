# Сайт сети здравниц «Окжетпес» — черновик

Статичный сайт без сервера: HTML + CSS + JS. Открыть локально: `python -m http.server 8777` в этой папке → http://127.0.0.1:8777

## Страницы
| Файл | Что это |
|---|---|
| index.html | Главная: о сети, три здравницы, направления лечения, сегменты клиентов, «Маршрут здоровья», FAQ |
| burabay.html | «Окжетпес», Бурабай |
| almaty.html | Almaty Resort, Алматы |
| issyk-kul.html | «Казахстан», Иссык-Куль (открытие 2026, предварительные заявки) |
| essentuki.html | «Казахстан», Ессентуки (Кавказские Минеральные Воды, РФ) |
| clients.html | Условия по сегментам: гости и семьи, госорганы, льготники, иностранцы, группы; правила отмены |
| corporate.html | Коммерческое предложение для компаний: пакеты, сетка скидок, программы, шаги |

Шапка, подвал и форма заявки общие — в `assets/site.js`. Там же `CONFIG`: номер WhatsApp для заявок и телефоны.

## Прейскуранты 2026
Утверждённые прейскуранты Алматы, Бурабая и Ессентуков (сканы распознаны локально) показаны в блоке «Цены» (`#prices`) на страницах almaty.html, burabay.html, essentuki.html: вкладки, поиск по услугам, прокрутка внутри блока.
- Данные: `tools/prices/<id>.py` → `python tools/prices/build.py` → `assets/prices/<id>.js` (подключён на странице перед site.js).
- `None` в данных = цена не распознана однозначно → красная ячейка «____». Такие цены заполнить вручную по бумажному прейскуранту.
- Проверки при разборе: Алматы и Бурабай — цена + НДС = итог; Ессентуки — руб. × 5 = тенге.
- Лёгкая версия (`light/`) берёт эти же данные: `python tools/build_light.py`.

## Что требует утверждения
- Все скидки и правила отмены — предложения (помечены на страницах).
- Цены: Алматы, Бурабай, Ессентуки — по утверждённым прейскурантам 2026; Иссык-Куль и готовые программы — «по запросу».
- Номер для заявок (`CONFIG.leadWhatsApp`) и телефоны Бурабая, Иссык-Куля и Ессентуков.
- Данные по номерам (категории, площади) — сверить с презентациями.
