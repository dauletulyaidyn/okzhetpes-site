# Облегчённая презентация · 1.1.0

Отдельная версия сети «Окжетпес». Полная презентация в корне не изменяется.

Открыть `light/index.html` напрямую или запустить из корня `python -m http.server 8777` и перейти на http://127.0.0.1:8777/light/.

Маршрут: общая страница с четырьмя филиалами → услуги выбранного санатория → контакты и расположение. На каждой странице доступны выбор другого филиала и ссылка на полную презентацию. Кнопка полного экрана доступна в поддерживающих её браузерах.

Страницы генерируются `python tools/build_light.py` (зависимость генератора: `beautifulsoup4`). Описания и контакты находятся в DATA, каталоги услуг автоматически переносятся из HTML полной презентации: JSON svc-*, путёвки, таблицы номеров и дополнительные возможности. Изменения исходных каталогов требуют повторного запуска генератора. CSS и JS независимы от полной версии. Внешние шрифты, библиотеки, аналитика и видеоплееры не загружаются. Изображения используются из существующей папки assets/photos. Для Иссык-Куля используется иллюстрация CSS, поскольку фотографии в текущем наборе нет.

Каждая услуга отображается отдельной строкой с ценой, категории имеют ссылки для быстрого перехода. На телефоне каталог идёт одной колонкой без горизонтальных таблиц. Красное поле означает незаполненную цену; суммы не выдумываются. Числовые тарифы Ессентуков сохранены из полной презентации с указанием даты источника (09.11.2026), без заявления о повторной проверке актуальности. Отдельная стоимость инфраструктуры и включение услуг в путёвку требуют подтверждения. Для SGL/DBL Бурабая предусмотрены отдельные строки.

Контакты и адреса сверены 10.11.2026:
- Алматы: https://almatyresort.kz/contacts/
- Бурабай: https://okzhetpes-burabay.kz/kontakty/
- Иссык-Куль: https://kazakhstanhealthresort.com/contacts/
- Ессентуки: https://kazakhstan-kmv.ru/contacts/

Контакты — публичные контакты санаториев; конфиденциальные документы не использовались. У Иссык-Куля сохранён статус предварительных заявок: официальный сайт указывает открытие в декабре 2026 года. Состав путёвок и стоимость уточняются у санатория. Описания услуг сокращены из существующих страниц; они не являются утверждёнными условиями продажи.
